# 🐪 Yalla, Julia! — Band 1

Arabisch für Ägypten (Masri) — interaktives Lernbuch mit Audio-Aussprache und Flashcard-Modus.

**Lesen & hören:** https://mohamedelhalwagy.github.io/yalla-julia/

### Auf dem iPhone installieren
1. URL in **Safari** öffnen
2. Teilen-Button → **„Zum Home-Bildschirm"**
3. Fertig — funktioniert danach komplett offline

### Neu bauen (Band 2 etc.)
```
python3 tools/build_app.py
```
Das erzeugte HTML enthält die iPhone-Audio-Fixes (Blob-URLs statt Data-URIs) und PWA-Unterstützung automatisch.
